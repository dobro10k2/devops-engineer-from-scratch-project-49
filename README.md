# Описание:

«Игры разума» — набор из пяти консольных игр, построенных по принципу популярных мобильных приложений для прокачки мозга. Каждая игра задает вопросы, на которые нужно дать правильные ответы. После трех правильных ответов считается, что игра пройдена. Неправильные ответы завершают игру и предлагают пройти ее заново.

_________________________________________________________________

# Требования:

- Python 3.10+
- Установленный uv пакетный менеджер

_________________________________________________________________

# Установка:

Клонируем репозиторий:

- git clone https://github.com/dobro10k2/devops-engineer-from-scratch-project-49.git
- cd devops-engineer-from-scratch-project-49

Установка пакета:

- make build
- make package-install

_________________________________________________________________

После установки все игры доступны через команды:

- brain-games
- brain-even
- brain-calc
- brain-gcd
- brain-progression
- brain-prime
